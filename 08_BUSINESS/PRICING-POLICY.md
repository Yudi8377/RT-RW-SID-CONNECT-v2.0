# RT/RW-SID CONNECT — Pricing Policy v1.0

Status: FRAMEWORK ONLY
Important: numeric prices below are NOT approved final prices.

## Pricing principles

Price should reflect feature scope, number of users/devices where relevant, organization size, support level, deployment complexity, integration/customization, and security/maintenance commitments.

## Initial pricing hypothesis for validation

These are test ranges only, not a public price list:

- Community: Rp0
- Pro: approximately Rp99.000–Rp299.000/month OR Rp999.000–Rp2.999.000/year depending on scope
- Institution: approximately Rp2.999.000/year and above depending on deployment scope
- Services: quoted separately based on actual work

Before publication, run a cost and support model and review Indonesian accounting/tax implications.

## Contribution amounts

Suggested contribution UI presets: Rp25.000, Rp50.000, Rp100.000, Rp250.000, Rp500.000, and custom. These are contribution choices, not feature prices.

## No price-locking in v2.0.1

The v2.0.1 technical release must not hard-code unapproved commercial prices into the core runtime. Commercial configuration should be versioned separately from the technical release where practical.
