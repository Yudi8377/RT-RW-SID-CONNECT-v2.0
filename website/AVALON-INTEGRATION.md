# Avalon UX integration — Smart Village

This branch adapts the visual language of TemplateMo 513 Avalon to the existing RT/RW CONNECT Smart Village public website. TemplateMo's Avalon page states that the template may be edited and used for commercial or non-commercial websites: https://templatemo.com/tm-513-avalon

## What changed
- Added website/avalon.css, a locally maintained Avalon-inspired design layer: warm editorial palette, square-edged cards, orange/red/yellow accents, and asymmetric masonry-style navigation blocks.
- Added #avalon-highlights linking to existing Layanan, Wilayah, Kabar Desa, Agenda, and Ruang Warga sections.
- Kept existing Smart Village content, Supabase config/runtime scripts, service actions, news/agenda loading, and 3D Coverflow integration intact.
- Added responsive layouts, keyboard focus treatment, and reduced-motion support.

## Scope and production notes
This is an adaptation of the template's visual language, not a wholesale copy of its source files. Existing service availability still depends on configured backends and role permissions. The mosaic is navigational and does not claim every feature is live.
