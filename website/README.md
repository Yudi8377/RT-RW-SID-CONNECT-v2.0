# Smart Village — Desa Cerdas Public Experience

Public website layer migrated from Hatchable v4 to a zero-cost GitHub Pages-compatible static stack.

## Scope
- Civic Editorial + Enterprise visual direction
- Living Map with RT/RW personalization
- Public Services catalog
- News / editorial layer
- Ruang Warga
- Agenda
- Jolie Business OS / local economy
- Public Data / Transparency / GIS entry points

## Boundary
This directory is the public-experience layer only. The operational SIM RT/RW–SID core remains unchanged and locked/pending.

## Zero-cost target
- GitHub repository + GitHub Pages for static hosting
- Supabase Free for future dynamic services
- No Hatchable runtime dependency
- No paid platform dependency in the public website

## Current deployment path
The site is under `/website/` so it can coexist with the existing RT/RW–SID application without replacing its root deployment.

Future dedicated-repository migration can move this directory verbatim when a separate public-website repository is available.
