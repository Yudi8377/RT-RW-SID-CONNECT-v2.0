# SOP UPDATE & UPGRADE

Update versi dan upgrade paket adalah dua hal berbeda.

## Upgrade paket
Community → Pro → Enterprise harus:
- mempertahankan Organization ID;
- mempertahankan data;
- mengubah entitlement secara dapat diaudit;
- tetap benar setelah restart/login.

## Acceptance
Setelah upgrade:
1. login;
2. cek plan;
3. cek fitur yang aktif;
4. uji fungsi penting;
5. cek status license/audit.

Rollback software tidak sama dengan downgrade paket.
