# MODEL COMMUNITY / PRO / ENTERPRISE

Paket adalah commercial entitlement; role adalah operational authorization.

Contoh entitlement:
- basic_services
- citizen_profile
- advanced_reports
- workflow_approval
- multi_region
- audit_export
- enterprise_integrations

Daftar entitlement sebaiknya berasal dari backend/config resmi, bukan hanya hard-code di UI.

**Community**: fitur dasar sesuai katalog.
**Pro**: fitur advanced sesuai katalog.
**Enterprise**: governance, kapasitas, integrasi, dan kontrol enterprise sesuai kontrak.

Jangan menjadikan nama paket sebagai security boundary.
