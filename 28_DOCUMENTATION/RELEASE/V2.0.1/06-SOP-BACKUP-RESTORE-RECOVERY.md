# SOP BACKUP, RESTORE & RECOVERY

Backup harus dapat dipulihkan. Backup yang belum diuji restore belum dianggap tervalidasi.

## Recovery
1. Hentikan transaksi aktif.
2. Catat versi, organisasi, dan waktu.
3. Simpan salinan artefak sebelum perubahan.
4. Gunakan backup yang diketahui valid.
5. Verifikasi integritas data.
6. Catat hasil recovery.

Jangan menghapus database lokal asli sebelum salinan recovery dan bukti insiden diamankan.
