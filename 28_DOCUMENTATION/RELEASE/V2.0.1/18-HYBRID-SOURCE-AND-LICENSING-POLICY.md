# Hybrid Source & Licensing Policy

## Terminologi
Produk ini menggunakan pendekatan **hybrid/source-available**, bukan otomatis “open source”.

Sebuah komponen hanya boleh disebut open source bila lisensinya memenuhi definisi open-source yang relevan. Kode proprietary, activation service, signing keys, commercial control plane dan aset berlisensi tidak boleh disamakan dengan source code yang tersedia untuk publik.

## Community
Community menyediakan fitur sesuai entitlement Community dengan model support/subscription Rp250.000/bulan per RT/RW sesuai terms yang berlaku.

## Pro / Enterprise
Entitlement Pro/Enterprise diterbitkan oleh sistem lisensi resmi dan tidak boleh dipalsukan melalui perubahan JavaScript/client.

## Open components
Untuk setiap dependency/repository:
- catat upstream;
- lisensi;
- versi;
- checksum/lockfile;
- perubahan lokal;
- kewajiban attribution;
- kewajiban source disclosure bila ada.

## Proprietary components
Signing private key, server secret, payment credentials dan service-role credentials tidak boleh berada di installer/client.

## Update obligation
Siklus support harus mencakup:
- bug fixes;
- security fixes;
- dependency updates;
- compatibility;
- release notes;
- documentation;
- recovery guidance.

## Tidak ada “open source immunity”
Ketersediaan source code tidak menghapus kewajiban PDP, keamanan, kontrak, pajak, PSE atau regulasi lain yang berlaku.
