# RT/RW-SID CONNECT v2.0.1 — HANDBOOK PENGGUNA

## Tujuan
RT/RW-SID CONNECT membantu Warga, RT, RW, dan Kelurahan/Desa mengelola informasi, layanan, data, dan aktivitas wilayah secara terstruktur.

## Sebelum instalasi
- Gunakan installer resmi.
- Verifikasi nama file dan SHA-256 bila tersedia.
- Pastikan ruang penyimpanan mencukupi.
- Untuk komputer organisasi, gunakan akun Windows dengan hak yang diperlukan.

## Instalasi
1. Jalankan installer resmi.
2. Ikuti wizard instalasi.
3. Setelah selesai, gunakan shortcut aplikasi.
4. Jangan memindahkan atau mengubah file aplikasi secara manual.

## Mode offline
Fungsi yang memang didukung secara lokal dapat digunakan tanpa internet. Data yang perlu dikirim kembali mengikuti mekanisme queue/sinkronisasi aplikasi.

## Sinkronisasi
Saat koneksi tersedia:
1. Pastikan profil/organisasi benar.
2. Jalankan sinkronisasi.
3. Periksa hasilnya.
4. Jangan menghapus database lokal sebelum proses recovery/sync selesai.

## Keamanan
Jangan membagikan password, memasang executable modifikasi, atau memberikan akses administrator kepada pengguna yang tidak membutuhkannya.

## Dukungan
Saat melaporkan masalah, sertakan versi aplikasi, OS, waktu kejadian, langkah reproduksi, dan pesan error/log yang tersedia.

> Dokumen ini melengkapi release artifact v2.0.1 dan tidak menggantikan Windows Acceptance Gate resmi.
