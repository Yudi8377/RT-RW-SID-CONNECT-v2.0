## Release rule

Do not publish v2.0.1 until the release workflow's A1–A16 validation evaluates every required gate to exactly PASS.

## Operational boundary

GitHub-hosted CI can prove the build/package/install/runtime-static portions, but it cannot honestly manufacture evidence for physical network disconnection, manual uninstall/retention inspection, or a real fresh Windows profile. Those observations require a disposable Windows environment with the exact RC artifact.
