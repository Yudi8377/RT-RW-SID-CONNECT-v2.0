## Evidence requirements

For every PASS, record at least one concrete evidence item:

- screenshot/photo, or
- exact observation with timestamp, or
- relevant local path/file existence, or
- application log excerpt, or
- before/after state for queue/sync/restart tests.

For A7–A11, capture the same test record identifier across the sequence so persistence and replay can be demonstrated.

For A13–A15, record the application installation path and the user-data path separately. Do not delete retained user data merely to obtain a PASS; the expected retention behavior must be observed and recorded.

## Final release decision

The release gate may move from **LOCKED** only when:

1. A1–A16 are all recorded as PASS;
2. no manual gate is marked FAIL;
3. evidence is attached or otherwise traceable for each manual gate;
4. the acceptance record identifies the exact installer SHA-256;
5. the acceptance was performed on a real Windows environment;
6. `hardening-v2.0.1` and `main` remain unchanged until the acceptance decision is formally recorded.

Until then:

**RELEASE GATE = LOCKED**
