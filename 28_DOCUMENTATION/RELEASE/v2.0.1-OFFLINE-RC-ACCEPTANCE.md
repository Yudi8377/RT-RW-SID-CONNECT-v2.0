## Required manual Windows acceptance

This gate must be executed on a real Windows machine. It is intentionally not marked PASS from CI alone.

1. Install the EXE using the normal NSIS flow.
2. Confirm installation completes without elevated/network dependency beyond Windows installer requirements.
3. Launch RT/RW-SID CONNECT.
4. Confirm the offline shell opens with network disconnected.
5. Confirm local database is created and persists after application restart.
6. Exercise one representative local record operation.
7. Exercise an offline queue operation and confirm pending state.
8. Restart the application and confirm queued data persists.
9. Restore connectivity and verify sync/replay behavior where the configured runtime supports it.
10. Verify migration/recovery behavior against a test copy before touching any real community data.
11. Uninstall through Windows Apps/Programs.
12. Confirm uninstall removes the application while preserving any intentionally retained user-data location according to the product policy.
13. Reinstall and confirm a clean first-run experience.
